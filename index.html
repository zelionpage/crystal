Pertanyaan umum

Apa itu Crystal 2?

Crystal 2 adalah proyek asisten digital dan ekosistem teknologi yang sedang dikembangkan.

Bagaimana cara menghubungi Crystal?

Kamu dapat menggunakan tombol WhatsApp pada halaman ini atau menghubungi nomor yang tersedia.

Apakah Crystal API sudah tersedia?

Belum. API dan developer portal masih menjadi bagian dari roadmap pengembangan.

Bagaimana pengajuan tier VIP/VVIP diproses?

Pengajuan akan menunggu tinjauan Owner. Persetujuan otomatis baru dapat digunakan setelah API dan ekosistem pembayaran tersedia dan terintegrasi.

Apakah website ini mendukung bahasa Inggris?

Ya. Gunakan tombol ID dan EN di bagian navigasi untuk mengganti bahasa.
